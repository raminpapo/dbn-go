## Introduction

dbn-go provides Golang bindings to [Databento's](https://databento.com) file format [Databento Binary Encoding (DBN)](https://databento.com/docs/knowledge-base/new-users/dbn-encoding), Historical API, and Live API.

### Project Information

- **Repository**: dbn-go
- **Language**: Go
- **License**: Apache License, version 2.0
- **Copyright**: 2024-2025 Neomantra Corp

### Key Features

1. **DBN File Format Support**: Read and parse Databento Binary Encoding files
2. **Historical API Client**: Access historical market data
3. **Live API Client**: Stream real-time market data
4. **Multiple Data Schemas**: Support for MBO, MBP, trades, OHLCV, and more
5. **Command-Line Tools**: Ready-to-use CLI applications
6. **Compression**: Built-in zstandard compression support

## Core Files Reference

### Main Data Types (structs.go)

The core message types implementing the DBN encoding:

- **RHeader**: Common record header (16 bytes)
- **Mbp0Msg**: Market-by-price depth 0 (Trade messages)
- **MboMsg**: Market-by-order messages
- **Mbp1Msg**: Market-by-price depth 1
- **Mbp10Msg**: Market-by-price depth 10
- **Cmbp1Msg**: Consolidated market-by-price depth 1
- **OhlcvMsg**: OHLCV candlestick data
- **ImbalanceMsg**: Order imbalance messages
- **SymbolMappingMsg**: Symbol mapping records
- **InstrumentDefMsg**: Instrument definitions
- **StatMsg**: Statistics messages
- **StatusMsg**: Trading status updates
- **BboMsg**: Best bid and offer records
- **ErrorMsg**: Error messages from gateway
- **SystemMsg**: System messages and heartbeats

### Constants and Enums (consts.go)

DBN encoding constants and enumeration types:

- **RType**: Record type identifiers
- **Schema**: Data schema definitions
- **SType**: Symbology types
- **Side**: Market side (Ask/Bid/None)
- **Action**: Order actions (Add/Cancel/Modify/Trade/Fill)
- **Encoding**: Data encoding formats (DBN/CSV/JSON)
- **Compression**: Compression types (None/ZStd)
- **InstrumentClass**: Instrument classifications
- **MatchAlgorithm**: Matching algorithms

### Parsers and Scanners

- **DbnScanner** (`dbn_scanner.go`): Stream DBN records from files
- **JsonScanner** (`json_scanner.go`): Stream DBN records from JSON files
- **Metadata** (`metadata.go`): DBN file metadata parsing

### Visitors Pattern

- **Visitor** (`visitor.go`): Interface for processing DBN records
- **NullVisitor** (`null_visitor.go`): No-op visitor implementation

## Usage Examples

### Reading DBN Files

```go
import dbn "github.com/NimbleMarkets/dbn-go"

file, closer, _ := dbn.MakeCompressedReader("data.dbn.zstd", false)
defer closer.Close()
records, metadata, err := dbn.ReadDBNToSlice[dbn.OhlcvMsg](file)
```

### Using Historical API

```go
import dbn_hist "github.com/NimbleMarkets/dbn-go/hist"

apiKey := os.Getenv("DATABENTO_API_KEY")
schemas, err := dbn_hist.ListSchemas(apiKey, "EQUS.MINI")
```

### Using Live API

```go
import dbn_live "github.com/NimbleMarkets/dbn-go/live"

client := dbn_live.NewLiveClient(config)
client.Authenticate(apiKey)
client.Subscribe(subscriptionRequest)
client.Start()
scanner := client.GetDbnScanner()
```
